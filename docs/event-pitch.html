Pillar A

On-device vs cloud — latency, cost, privacy

~2.3× faster, free, and fully private — at competitive accuracy. Ships on-device today.

Pillar B

Styling personalization — Fireworks-native

  • Eval built on Eval Protocol (Fireworks' own tool): slop + intent + quality judges over real dictation traces, scores pushed to Braintrust.
  • Production baseline: slop 4.9/1k · intent 0.997 · quality 0.868 — prompt-tuning vs raw is the measured win.
  • Full SFT pipeline on Fireworks (dataset + fine-tune jobs on Qwen3 / Muse Glimmer / deepseek-flash).

Honest: tuned-inference hit real Fireworks deployment friction — which we documented as feedback, reproducing a prior report point-for-point. Depth, not a dead end.
